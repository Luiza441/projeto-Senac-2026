# *Viajei*

 O projeto *Viajiei* é um projeto criado para compartilhar experiências que já vivemos, para que outras pessoas também possam usufruir da mesma experiência. Essas experiências podem ser sobre qualquer tema (Livros, filmes, séries, cozinha e etc...)

O projeto *Viajei* é recomendado para +14 (Quatorze) anos
